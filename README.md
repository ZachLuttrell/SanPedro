# SanPedro

An endless Sonoran desert to wander. Open `index.html` to play.

## Mockups

- `mockups/valley-3d.html` — a look-and-feel study of the same valley in 3D. It reuses the
  2D game's world functions unchanged, and switches between a voxel world and a smooth mesh
  (`V`). Needs a network connection the first time, to load three.js.
